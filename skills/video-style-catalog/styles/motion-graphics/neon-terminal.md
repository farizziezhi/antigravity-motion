# Neon Terminal
Motion graphics
Pitch-black CRT terminal windows and glowing neon-green phone outlines floating over drifting green hexadecimal rain.

## Palette
| role | hex | note |
| --- | --- | --- |
| terminal void | #050505 | pitch-black full-screen canvas |
| neon system green | #22FF88 to #00E676 | phone frames, safe prompts, live caption highlights |
| alert magenta | #FF2E88 | threat prompts, error codes, mid-climax pause screen |
| lock amber | #FFB300 | key security icon, warning headlines, top category dot |
| dim hex rain | ≈#0B3D22 | slow vertical background code characters (~15% opacity) |

## Materials & texture
Electric dark-room CRT screen look with soft neon outer glow on vector strokes and dimmed cascading hexadecimal text behind crisp thin-bordered interface windows.

## Typography
Monospace terminal font across nearly every element, complete with colored shell headers (`user@device:~$` in green, `sender@unknown:~$` in magenta). Bold sans-serif `#FFB300` orange handles urgent warning headlines, a small top-right `● GUIDE • SAFETY` tag tracks every frame, and bottom captions render as `> command` lines with an active `#22FF88` keyword and blinking block cursor.

## Composition
One centered glowing phone outline or framed `[x]` terminal window per scene over moving hex rain, keeping captions anchored at the bottom; occasional multi-lock grid frames tighten density right before a full-screen magenta pause card.

## Mood
Tense, nocturnal, and cyber-thriller urgent, balanced by a persistent top educational tag that keeps the tone instructional.

## Signature elements
- Slow cascading green hexadecimal rain at ~15% opacity over `#050505` black.
- Thin-stroked glowing neon phone mockups and `[x]`-titled terminal windows.
- Shifting shell prompts contrasting `user@device` (green) against `sender@unknown` (magenta).
- Command-line bottom caption (`> text`) with `#22FF88` active highlight and blinking cursor.

## Recipe
1. Fill a `#050505` canvas with slow-scrolling dim green hex characters (`≈#0B3D22`) at ~15% opacity; never leave the background pure flat black.
2. Draw phone outlines and `[x]` terminal frames in glowing `#22FF88`–`#00E676`, reserving `#FF2E88` for hostile prompts or `404` alerts and `#FFB300` for one critical lock/warning object per scene.
3. Add a persistent small `#FFB300` category label (`● [CATEGORY]`) in the top right of every frame.
4. Set terminal windows and `> ` bottom captions in monospace with live `#22FF88` word highlights and a blinking block cursor, using bold `#FFB300` sans for climax warnings.
5. Animate text with typewriter reveals, pop terminal windows into place, count numeric readouts up, and insert one full-frame `#FF2E88` text pause before the warning finale.

## Don'ts
- Do not add human characters, paper textures, or daylight backgrounds.
- Do not mix more than one `#FFB300` focal object alongside the green and magenta system colors.
- Do not omit the subtle hex rain or the glowing vector stroke treatment.

## One-frame test
- Does faint green hexadecimal rain drift behind `#050505` black space?
- Are UI elements built from glowing neon green/amber/magenta line frames with shell prompts?
- Is the bottom caption formatted as a `> ` command line with a blinking block cursor?

## Base prompt
Vertical 9:16 dark CRT neon terminal motion graphics frame on pitch-black (#050505) with dim green hexadecimal rain at 15% opacity, centering a glowing neon-green (#22FF88) thin-lined smartphone mockup and a framed terminal window showing an amber (#FFB300) line-art padlock, magenta (#FF2E88) alert prompt, bold amber sans warning title, small top-right safety badge, and a bottom monospace command caption with a blinking block cursor.
