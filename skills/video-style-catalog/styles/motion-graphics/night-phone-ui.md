# Night Phone UI
Motion graphics
Late-night dark bedroom framing an oversized smartphone mockup displaying realistic app screens with yellow CTA traps and red danger stamps.

## Palette
| role | hex | note |
| --- | --- | --- |
| night wall navy | #1B2A4A | dimly lit late-night room walls |
| dark teal floor | #2A7F6F | subtle room floor plane and furniture grounding |
| maroon drape | ≈#6E1D2A | heavy bedroom curtains framing the background |
| bright phone screen | ≈#F6F4EE | cream-white app interface acting as the main light source |
| alert yellow | #FFC93C | headline keyword highlights, risky buttons, final summary card |
| danger red & bank green | #0E7A5F | trustworthy app UI green, contrasted with `≈#E53935` red danger tags |

## Materials & texture
Clean flat 2D cartoon room backdrop paired with sharp, semi-realistic smartphone UI mockups (status bars, clock icons, app grids, system dialogs) glowing like the sole bright screen in a dark bedroom.

## Typography
Bold white sans-serif headlines set inside black upper pills (`≈#111111`) with one `#FFC93C` yellow keyword above the phone, paired with clean crisp realistic UI sans inside messaging threads, file-detail sheets, and permission popups. Ends on a large `#FFC93C` yellow `1 RULE` summary card accented by red danger tags.

## Composition
Centered oversized smartphone serves as the primary "actor" over the quiet `#1B2A4A` night bedroom backdrop, topped by the black headline pill. One single emotional scene flips the balance, placing a flat cartoon person large in center foreground with a tiny app screen in front.

## Mood
Suspenseful, late-night cautionary thriller anchored by recurring `23:0x` late-hour clock stamps.

## Signature elements
- Consistent `#1B2A4A` navy bedroom backdrop with maroon drapes and `23:0x` wall/status-bar clocks.
- Crisp realistic smartphone UI screens (chat, file info, system permission prompts, banking UI) acting as the main stage.
- Bold black upper headline pill highlighting one `#FFC93C` yellow keyword above the phone.
- Red danger tags/cross-outs (`≈#E53935`) paired with bright `#FFC93C` trap buttons and a final yellow `1 RULE` card.

## Recipe
1. Build one recurring nocturnal bedroom stage: `#1B2A4A` navy walls, `≈#6E1D2A` maroon curtains, `#2A7F6F` dark teal floor, lamp, and a clock reading `23:0x` matching the phone status bar.
2. Center a large bright `≈#F6F4EE` smartphone mockup running clean realistic interface screens (chat bubbles, file details, permission dialogs, `#0E7A5F` secure app UI).
3. Float a black upper headline pill above the phone in bold white sans with one `#FFC93C` yellow keyword.
4. Mark traps visually with red `≈#E53935` danger pills or red cross-outs and `#FFC93C` yellow action buttons; show at most one flat cartoon character shot for an emotional beat.
5. Swap phone screens via crisp tap-like cuts and close on a full-screen `#FFC93C` yellow `1 RULE` checklist card.

## Don'ts
- Do not brighten the surrounding bedroom into cheerful daylight.
- Do not replace realistic UI typography with hand-drawn doodle fonts inside the phone screen.
- Do not overcrowd scenes with a cast of talking cartoon characters.

## One-frame test
- Does a bright realistic smartphone screen command center stage over a `#1B2A4A` late-night bedroom?
- Do clocks read around `23:0x` while a black top pill highlights one `#FFC93C` keyword?
- Are traps clearly flagged with red danger tags and yellow buttons?

## Base prompt
Vertical 9:16 suspenseful nocturnal motion graphics frame set inside a dimly lit navy (#1B2A4A) bedroom with maroon curtains (#6E1D2A), dark teal floor (#2A7F6F), and a wall clock at 23:05, centering an oversized smartphone displaying a clean realistic cream-white (#F6F4EE) system permission dialog with a red danger extension tag (#E53935) and bright yellow (#FFC93C) action button, topped by a black pill headline with one yellow highlighted word.
