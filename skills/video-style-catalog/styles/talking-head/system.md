# System
Talking-head edit · Treatment family 4 (Video as a small window inside a UI system)
Speaker shrunk into a small top card above a full-screen AI chat panel with blue progress bars, top command bar, and dark typing-cursor captions.

## Palette
| Role | Hex | Note |
|---|---|---|
| Pale UI backdrop | `≈#E8EDF5` | Light cool blue-gray system background |
| Panel white | `≈#FFFFFF` | Rounded central chat panel and reply surface |
| Caption bar dark | `≈#141619` | Translucent dark rounded caption bar |
| Neon lime accent | `≈#C6FF00` | Caption keywords, blinking cursor, send button |
| Electric blue | `≈#2F4BF0` | Live progress bar fill and closing CTA button |
| Reply gray | `≈#EEF1F5` | System response card inside chat thread |

## Materials & texture
Clean, crisp SaaS interface aesthetic over a smooth pale `≈#E8EDF5` gradient. Overlay captions sit inside a semi-transparent dark rounded bar (`≈#141619` at `≈80%` opacity), contrasting against bright white UI cards and thin vector badges.

## Typography
System UI sans-serif throughout. Lower-third captions live inside a dark translucent bar featuring a tiny `"CC"` badge on the left, `#FFFFFF` body text, `≈#C6FF00` colored keywords, and a blinking lime block cursor (`▍`) at the trailing edge to suggest live system typing.

## Composition
Inverts the usual talking-head hierarchy: during UI segments, the speaker shrinks into a small rounded video card or strip near the top while a full-screen white chat interface commands the center, topped by a pill command bar (`"✦ Command..."`). Returns to full-screen speaker shots only during non-UI lines, ending on a lime-ringed circular avatar card with a `≈#2F4BF0` CTA pill.

## Mood
Organized, automated, and tech-product focused, showcasing an active software workflow rather than raw speaker energy.

## Signature elements
- Inverted layout hierarchy: speaker shrunk into a small top strip/card above a dominant full-screen white chat panel (`"SYS"` + `"CHAT"` header, black command bubble, `≈#EEF1F5` reply card, `≈#2F4BF0` percentage progress bar advancing e.g. `72%`, `"Type adjustment..."` input with `≈#C6FF00` send circle).
- Dark translucent rounded caption bar (`≈#141619`) carrying a `"CC"` tag, `#FFFFFF` text, `≈#C6FF00` lime keywords, and a blinking lime cursor (`▍`).
- Top pill prompt bar (`"✦ Command..."`) with a round send icon framing the screen like an active workspace.
- Closing card pairing a lime-bordered circular portrait, bold two-word title with the second word highlighted lime, and a `≈#2F4BF0` pill button.

## Recipe
- Place UI panels over a pale `≈#E8EDF5` backdrop; restrict the palette strictly to `#FFFFFF`, `≈#141619`, `≈#C6FF00`, and `≈#2F4BF0`.
- Shrink the talking-head shot into a compact top strip or small rounded card whenever the central chat interface appears; expand to full-screen only on unadorned speech beats.
- Build the hero chat panel as a white rounded container with `"SYS"` + `"CHAT"` header, black user prompt bubble, `≈#EEF1F5` system reply card (`"Ready, updated all layers."`), advancing `≈#2F4BF0` progress bar (`72%` -> `100%`), and input field with a `≈#C6FF00` circular send button.
- Add a top command pill (`"✦ Command..."`) above the window to reinforce the live-software frame.
- Render all captions in a `≈#141619` semi-transparent rounded bar with a small `"CC"` badge, `#FFFFFF` words, `≈#C6FF00` keywords, and a trailing blinking `▍` lime cursor.

## Don'ts
- Never keep the speaker full-screen behind small corner graphics during system-action beats; shrink the speaker into a small window.
- Never use chunky white caption pills or solid black text inside lime highlighter blocks.
- Do not include numbered checklists or flat design-grid artboards.
- Avoid white caption pills with numbered checklists over close-ups as in Lime Punch, and avoid cream gridded artboards or red-orange solid block wipes as in Flat Artboard.

## One-frame test
- Is the speaker minimized into a small top card/strip above a central white chat UI with a `≈#2F4BF0` percentage progress bar?
- Does the lower caption use a dark translucent bar with a `"CC"` badge, `≈#C6FF00` lime text highlights, and a trailing `▍` cursor?
- Is there a `"✦ Command..."` top input pill framing the screen as an active app?

## Base prompt
Automated software-interface talking-head video treatment inverting visual hierarchy so a clean white AI-style chat panel dominates a pale blue-gray (#E8EDF5) screen while the speaker shrinks into a small top video strip. The central UI panel shows a black command bubble, soft gray reply card, live electric blue (#2F4BF0) percentage progress bar, and a revision input box with a neon lime (#C6FF00) send button, framed beneath a top command pill bar. Captions sit inside a dark translucent rounded bar with a tiny CC badge, white text, neon lime keywords, and a blinking lime block cursor at the end.
