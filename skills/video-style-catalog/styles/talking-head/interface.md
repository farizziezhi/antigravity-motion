# Interface
Talking-head edit · Treatment family 1 (Full graphic screen replaces video)
Bright mobile UI mockups, chat threads, search lists, and rounded blue notifications alternating full-screen with talking-head shots.

## Palette
| Role | Hex | Note |
|---|---|---|
| Canvas light gray | `#F5F6F8` | Clean background for full-screen UI views |
| Card surface | `≈#FFFFFF` | Notification cards, search bar, list panels |
| Incoming bubble | `#E9EBEE` | Neutral gray incoming message bubble |
| Primary ink | `≈#111318` | Bold row titles and input prompts |
| Secondary subtext | `#8A8F98` | Muted gray descriptions and timestamps |
| Accent app blue | `#2563EB` | Outgoing bubbles, send button, icons, hero number |

## Materials & texture
Crisp, flat digital UI surfaces with large rounded corners (`16` to `20 px`) and subtle soft drop shadows beneath floating notification cards only. No paper grain, noise, or heavy gradients.

## Typography
Clean system UI sans-serif (SF Pro, Inter, or Roboto style). Bold dark titles pair with small `#8A8F98` gray subtext, white text sits inside `#2563EB` outgoing chat bubbles, and a single oversized `#2563EB` numeral + unit appears near the end. Subtitles follow the lower-third plain lowercase sans pattern when over footage.

## Composition
Strict full-screen alternation between full-frame talking-head shots and full-screen mobile app mockups. UI screens never shrink into small corner overlays; they take over the entire frame except for a brief floating notification banner over video.

## Mood
Light, everyday, and familiar, evoking the clean utility of native mobile apps.

## Signature elements
- Full-screen chat mockup with a small circular top avatar, `#E9EBEE` incoming bubbles, `#2563EB` outgoing bubbles, and a bottom input bar with a round blue send button.
- Full-screen search bar paired with a clean icon-row list separated by hairline dividers.
- Floating rounded notification card (`16` to `20 px` radius, soft shadow, blue app icon) briefly overlaid on talking-head footage.
- One oversized `#2563EB` punchline numeral (such as `"24 HRS"`) topped by a small black label on `#F5F6F8`.

## Recipe
- Set full-screen UI backgrounds to `#F5F6F8`, primary text to `≈#111318`, subtext to `#8A8F98`, and all interactive accents to `#2563EB`.
- Build 2 to 3 complete UI views: (1) a floating rounded notification card (`16` to `20 px` radius, soft shadow) over video; (2) a full chat screen (`#E9EBEE` incoming vs `#2563EB` outgoing bubbles, bottom input + round blue send button); (3) a search field over an icon list with hairline dividers.
- Keep list rows structured as bold title + small `#8A8F98` subtitle (for example `"commuter / relies on routing"`, `"courier / delivers daily stops"`).
- Reserve one closing or climax `#F5F6F8` card for a giant `#2563EB` figure below a small black caption (`"paused for"` / `"24 HRS"`).

## Don'ts
- Never shrink UI screens into corner boxes or picture-in-picture widgets.
- Do not add dark mode panels, neon glows, or textured backgrounds.
- Avoid introducing warm colors or a second brand hue beyond `#2563EB`.
- Do not keep the talking-head room visible behind floating yellow sans keywords, cream serif-sans cards, or white line-icon rows above the head as in Clean.

## One-frame test
- Does a graphic frame look like a full-screen `#F5F6F8` native mobile app screen with `#2563EB` accents?
- Are all cards and message bubbles shaped with generous `16` to `20 px` rounded corners?
- Do talking-head shots and full-screen UI mockups alternate completely rather than sharing split layouts?

## Base prompt
Bright modern talking-head video treatment alternating cleanly between full-frame speaker shots and full-screen light-mode mobile UI mockups on a #F5F6F8 canvas. Clean system sans-serif typography pairs bold near-black titles with muted gray (#8A8F98) subtext and vivid app blue (#2563EB) accents. Includes a rounded notification banner with a soft drop shadow, a full-screen chat view with #E9EBEE incoming bubbles and #2563EB outgoing bubbles plus a round blue send button, a search bar above a hairline-divided icon list, and one giant blue numeral card. Crisp flat digital surfaces, 16-20px corner radii, no dark textures.
